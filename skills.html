Mobile-first

Every layout starts at 320px and scales up — fluid grids, flexible type and no horizontal scroll on any device.

Clean & maintainable

Semantic HTML, consistent naming and commented CSS so the next developer (or future me) can pick it up quickly.

Tested, not assumed

Cross-browser and cross-platform checks, keyboard testing and careful debugging before anything ships.

Fast & findable

Optimised assets, sensible load order and on-page SEO basics so pages are quick to load and easy to find.
