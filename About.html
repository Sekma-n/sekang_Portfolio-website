About

The developer behind the code.

I'm Sekang — a website developer building responsive, user-friendly sites with HTML, CSS, JavaScript and Java. Here's a little more about how I work and what I'm looking for.

I'm a website developer based in South Africa with a strong focus on clean, maintainable code and interfaces that just work — on every screen, in every browser.

My toolkit centres on HTML5, CSS3, JavaScript and Java, with SQL for anything that needs a database behind it. I lean on Bootstrap and Tailwind for fast starts, but I'm comfortable working without them too — writing the CSS by hand when the design calls for it, and keeping the three layers (structure, presentation, behaviour) cleanly separated.

Most of what I do is responsive web design and front-end development: taking a design or an idea and turning it into a working page that looks right at 320 px as well as 1920 px, loads quickly, and handles the messy edge cases — long words, missing images, slow connections — without falling apart.

I care about the boring details too: alt text on images, keyboard navigation, sensible focus states, meaningful page titles. They're the difference between a site that ships and a site that actually works for the people using it.

01 — Principles

How I work

01

Structure, style, behaviour

Semantic HTML for meaning, CSS for presentation, JavaScript for interaction. Keeping the three layers separate means pages stay easy to read, maintain and extend.

02

Responsive by default

Fluid layouts first, breakpoints only where the content actually needs them. Tested at 320 px upward so nothing is clipped and nothing forces horizontal scrolling.

03

Fast & findable

Speed and on-page SEO built in from the start — semantic markup, optimised assets, sensible heading order — not bolted on after launch.

04

Tested across browsers

Debugging and testing across browsers and platforms, so what ships actually works everywhere — not just in the browser I happened to build it in.
